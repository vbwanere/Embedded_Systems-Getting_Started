# AtMega32u4-Getting-Started
Bare metal C-programming test code for AtMega-32u4 for blinking on board LED.
### Steps:
1. Clone the repo `Embedded_Systems-Getting_Started`.
2. Go inside the folder `ItsyBitsy-AtMega32u4-main`.
3. Open the folder in Linux/ Windows Terminal.
4. Know the port name. On Linux - use `lsusb`.
5. type: `make`
6. type: `make flash PORT=/dev/ttyACM0` (port is `ACM0`).
